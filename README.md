# Design Viral

Duplicação do [clickmax.io/all](https://clickmax.io/all) transformada em playground de motion design:

- **/motion** — a página /all com cada bloco animado por um motion do catálogo, com botão flutuante à direita para trocar o motion ao vivo e copiar o prompt.
- **/motion/biblioteca** — os 42 motions (texto, data, transitions, texture, 3D, code, interface) com filtros, prompts de vibe coding e código de exemplo.
- Captura de leads (nome, email, telefone) integrada ao CRM do Clickmax (projeto **Campanhas virais**, funil **UX Motion**) via Browser SDK.
- CTAs do workshop apontando para https://lp.designengineer.com.br/ com UTMs de origem.

Deploy: https://designviral.vercel.app/motion

## Rodando local

```bash
npm install
npm run dev
```
